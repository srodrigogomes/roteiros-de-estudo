# Roteiros de Estudo

Site feito com Next.js (App Router) e React. Dados em arquivos JSON (pasta `data`) e texto de apoio vindo da API pública da Wikipédia.

## Como executar
1. Instalar o Node.js (versão 18 ou mais nova).
2. `npm install`
3. `npm run dev` e abrir http://localhost:3000

## Como gerar o build estático
1. `npm run build` (o site estático fica na pasta `out`)
2. Para ver o resultado: `npx serve out`
