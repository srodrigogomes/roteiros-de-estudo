# Roteiros de Estudo

Projeto web desenvolvido com Next.js para organizar roteiros de estudo.

## Como executar
1. Instale o Node.js.
2. Baixe o projeto pelo GitHub.
3. No terminal, execute `npm install`.
4. Execute `npm run dev`.
5. Acesse http://localhost:3000.

## Feito até agora
- Estrutura inicial do projeto.
- Cabeçalho e estilos.
- Dados em JSON.
- Listagem de roteiros com filtros.
- Página individual de roteiro.
- Tratamento de páginas não encontradas.
- Versionamento com Git e GitHub.
